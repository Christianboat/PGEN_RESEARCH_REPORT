# 🌍 Proximus Generation (PGEN) — Mentorship Research Dashboard

Welcome to the **PGEN Mentorship Research Dashboard** 📊  
This project visualizes insights from **104 student applications** to the PGEN Mentorship & Training Program.  
Built with **HTML, CSS, and Chart.js**, the dashboard provides an interactive way to explore the data.

---

## ✨ Features
- 📈 **Interactive Charts** – gender, career interests, skills, performance, and subject-career alignment.  
- 🏫 **Class Views** – filter results per class or compare between classes.  
- 📂 **Data Access** – download CSV summaries for offline analysis.  
- 🖨 **Export Options** – print or save reports as PDF.  
- 📱 **Responsive Design** – optimized for desktop, tablet, and mobile screens.
